# <p align="center"><i><b>Mirage Feathers</b></i></p>

I like games where you are in a hell of bullets in some form or another. While my ultimate dream is to get something like [_Under Defeat_](https://store.steampowered.com/app/2869510/UNDER_DEFEAT/) in 3D (sadly it's DX12), _Mirage Feathers_ is a fun throwback. I'll admit I can barely tell what's happening sometimes, but it's still a rollercoaster ride of things blowing up everywhere. The effect for one of the levels where you're flying downwards after traveling above the clouds is probably my favorite moment in the game.

Thankfully, the game largely `just works` in 3D. There's not really any _huge_ issues that I could see in normal gameplay.
